# 画像重複チェッカー

指定フォルダ内の「同じ／よく似た」画像をグループ化して表示し、
選択した画像をゴミ箱へ送る、または別フォルダへ移動できるWindows向けツールです。

## 機能

- pHash(知覚ハッシュ)による類似画像の検出。類似度のしきい値を調整できます
- フォルダを読み直さずに、しきい値だけ変えてグループを組み直せます
- 各グループで「最大(ファイルサイズが一番大きいもの)以外」をまとめて選択できます
- 複数ページにまたがって選択した画像を、まとめて削除・移動できます
- サムネイルサイズ(小・中・大)の切り替え、コンパクト表示
- サブフォルダも含めてスキャンできます

対応形式: bmp, gif, jpg, jpeg, png, tif, tiff, webp

## 必要環境

- Windows
- Python 3.x
- ライブラリ(Pillow, imagehash, send2trash)

```
pip install -r requirements.txt
```

`send2trash` を入れない場合も動作しますが、**削除が「ゴミ箱」ではなく完全削除になります**(元に戻せません)。通常は入れておくことをおすすめします。

## 使い方

1. `画像重複チェッカー.pyw` をダブルクリックして起動します
2. 「参照...」で対象フォルダを選びます
3. 「類似度のしきい値」を調整します(小さいほど、ほぼ同一の画像だけを拾います)
4. 「スキャン開始」を押します
5. 表示された画像をクリックして選択し(赤枠)、「選択した画像をゴミ箱へ」または「選択した画像を移動...」で整理します

画像をダブルクリックすると、既定のアプリで開きます。右クリックでも、開く・削除・移動ができます。

## 注意

- 削除・移動は実際のファイルに対して行われます。実行前に確認ダイアログが出ますが、大事な画像はバックアップしてから使ってください
- 実行中にエラーが起きると、同じフォルダに `error_log.txt` が作られます
